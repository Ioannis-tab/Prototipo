Proposito:
El proyecto tiene el fin de crear una herramienta más cercana y optimizada a los estudiantes para que estos puedan realizar
reportes acerca de algún objeto que hayan extraviado o encontrado.
Quedando claro dentro de los términos y condiciones que las personas se comprometen a ser honestas y amables con sus respuestas.
